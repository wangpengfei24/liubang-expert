# 刘邦 · 帝王谋略顾问（liubang-expert）

一个 WorkBuddy 专家包：以汉高祖刘邦的第一人称视角，回答用人、形势决断、分利结盟、逆风翻盘这类问题。

他不讲编年史，也不掉书袋。他是个四十八岁起兵、七年取天下的布衣天子，说话带泥腥气，判断带血腥气——给的是能拿去用的决断。

## 他会怎么答

开篇第一句就是结论，然后固定三段：

1. **乃公的判断** — 一句话说清打 / 忍 / 等 / 让 / 换
2. **这么办** — 怎么用人、怎么分利、怎么布局
3. **风险在哪** — 什么信号出现就该改主意，败了怎么收

讲道理必落到楚汉真事上：鸿门宴、汉中就国、明修栈道暗度陈仓、彭城之败、荥阳对峙、封韩信齐王、垓下合围、白登之围、白马之盟。引文标出处（《史记·高祖本纪》《史记·淮阴侯列传》《汉书·高帝纪》），随后立刻翻成大白话。

史实不编。记不真切就明说"这个细节乃公记不清了"；野史演义用时会注明。权谋讲生存智慧，不下作恶的具体操作指导。

## 安装

把整个 `liubang-expert/` 目录放到专家目录：

```
C:\Users\<你>\.workbuddy\plugins\marketplaces\my-experts\plugins\
```

然后注册，使其在「专家中心 - 我的专家」中可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

（`scripts/` 指 WorkBuddy 内置 `expert-manager` 技能包下的脚本目录）

## 修改

改名/换标签/改描述都可以直接编辑 `plugin.json` 和 `agents/*.md`，改完重新跑一次注册脚本。

注意：以下几项是专家的身份标识，**不要改**，改了专家会丢失——`plugin.json` 的 `name`、`agentName`、专家目录名、`agents/` 下的 `.md` 文件名。

## 头像

`avatars/expert.png` 为自动生成，可手动替换：PNG/JPG，512×512，不超过 500KB。
